# 🎬 ВечірКіно — Локальний рандомайзер фільмів на вечір

Персональний вебсайт для легкого та швидкого вибору ідеального фільму на вечір без довгих пошуків і сумнівів.

## 🚀 Як користуватися (Локально)

### Спосіб 1 (Рекомендований): Через локальний сервер
1. Двічі клацніть файл [`start.bat`](file:///C:/Users/Home/.gemini/antigravity-ide/scratch/movie-picker/start.bat) у папці проєкту.
2. Автоматично відкриється браузер за адресою: [http://localhost:3000](http://localhost:3000).

### Спосіб 2: Прямо через браузер (без сервера)
- Просто відкрийте файл [`index.html`](file:///C:/Users/Home/.gemini/antigravity-ide/scratch/movie-picker/index.html) у вашому браузері (Chrome, Edge, Firefox тощо).

## 🌟 Основні можливості та фішки

1. **Картка фільму посередині**:
   - Великий постер високої якості (з TMDB).
   - Рейтинг IMDb, рік випуску, тривалість у годинах та хвилинах.
   - Назва українською та мовою оригіналу, режисер, теги жанрів.
   - Короткий інтригуючий опис сюжету.

2. **Кнопки швидкого рішення**:
   - ⏭️ **«Пропустити»** (`[Пробіл]` або `[↓]`): показує інший випадковий фільм, залишаючи цей у списку.
   - 👎 **«Не подобається»** (`[←]` або `[A]`): виключає фільм назавжди (ніколи більше не покажеться), переносить у чорний список.
   - 👁️ **«Вже дивився»** (`[→]` або `[D]`): позначає фільм як переглянутий і назавжди виключає з рандомайзера.
   - 🍿 **«Буду дивитися сьогодні!»** (`[Enter]` або `[W]`): переможець вечора! Запускає святкове конфеті, відкриває модальне вікно з трейлером та посиланнями для пошуку (Google, Megogo, Sweet.tv, JustWatch, IMDb).

3. **Захист від випадкових кліків (Скасування / Undo)**:
   - Якщо випадково натиснули «Не подобається» чи «Вже бачив», з'являється плаваюче сповіщення з кнопкою **«Скасувати»** або можна натиснути `Ctrl+Z` / кнопку у верхній панелі.

4. **Керування списками (Списки)**:
   - Перегляд усіх переглянутих стрічок та чорного списку.
   - Пошук за назвою.
   - Можливість у будь-який момент повернути будь-який фільм назад у рандомайзер в один клік.

5. **Гнучкі фільтри під настрій**:
   - За жанрами (Фантастика, Трилер, Комедія, Детектив, Драма, Жахи тощо).
   - За рейтингом (7.5+, 8.0+, 8.5+).
   - За роками (Сучасні 2020+, 2010-ті, 2000-ні, 90-ті, Класика).

6. **Повна приватність та збереження**:
   - Усі дані зберігаються у вашому браузері (`localStorage`).
   - Можливість експорту/імпорту резервної копії в JSON файл.
   - Можливість додавати власні фільми через кнопку «➕ Додати фільм».
